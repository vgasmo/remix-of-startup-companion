## 🔴 Not fixed — need product/architecture decision

### Security

- **SEC-1 (false positive, no action):** The scan flagged `profiles.calendar_feed_token` as directly readable. It is actually a SHA-256 hash (never the raw token), column-level `SELECT` is already revoked from `anon`/`authenticated` in migration `20260610010843`, and reads go via SECURITY DEFINER RPCs `get_my_calendar_token_status()` / `set_my_calendar_token()`. Documented here so the scanner's false positive doesn't drive a redundant migration.
- 74 "SECURITY DEFINER function is executable by anon/authenticated" warnings — expected pattern for `has_role`, `has_workspace_access`, and similar helpers used inside RLS policies. Documented in project memory. No action.

### UX

- **UX-P0-2 (systemic i18n bug):** `date-fns` `format()` is called with `{ locale: pt }` unconditionally in **17 files** — dashboards, dataroom, community feed, admin announcements, portfolio tables. English users see Portuguese month/weekday names. Helper (`src/lib/dateLocale.ts`) is now shipped; each callsite needs a mechanical swap: `import { pt } → import { useDateLocale }` + `const dl = useDateLocale();` + `{ locale: dl }`. Files: `SharedDataroom.tsx:180`, `AdminDatarooms.tsx:245`, `DocumentReviewPanel.tsx:237,345`, `DataroomTab.tsx:325,398,527`, `TemplateRequestsPanel.tsx:84`, `AccelerationCalendarSection.tsx:220`, `CommunityFeed.tsx:284`, `ConsultorSessionsToday.tsx:68`, `PortfolioPerformanceTable.tsx:192,286`, `CockpitPortfolioOverview.tsx:180,191`, `AdminTemplateRequestsManager.tsx:142`, `AdminAnnouncementsManager.tsx:408`. Say the word and I'll ship the batch.
- **UX-P1-4:** `defaultValue` fallbacks passed to `t()` are Portuguese in `MySupportTeamCard.tsx:57-137` and (previously) `ClaimRequestsQueue.tsx` — fixed here for Claim, but the broader pattern should be flipped to English (source-language convention) or removed. Consider ESLint rule.
- **UX-P1-5:** `src/App.tsx:183` — bare `Navigate to="/settings"` from `/integrations-setup` with no toast/banner. Product decision: keep silent or notify.
- **UX-P1-6:** `src/App.tsx:104-112` — `claimExemptPaths` hardcoded array; any new founder-facing route added later can unexpectedly punt founders to `/claim-startup`. Recommendation: derive from route metadata.
- **UX-P1-7:** Two spinner instances (`ProtectedRoute` + `SuspenseFallback`) render sequentially on protected navigations. Consolidate into one shared `<LoadingScreen/>` component.
- **UX-P2-12:** 62 delete handlers exist but only 19 files use `AlertDialog`. Follow-up pass to find destructive actions lacking confirmation (CRM lead delete, bulk actions).

### Performance

- **PERF-P0-1:** `src/hooks/useEcosystemItems.ts:52-262` — 4-round-trip waterfall (`workspaces` → `workspace_users` → `profiles_safe` → `funnel_items` → `profiles_safe`) with client-side filtering on up to 1000 rows. Recommend a single Postgres RPC `get_ecosystem_items` with server-side pagination.
- **PERF-P0-2:** `useEcosystemItems.ts:85,117` — `.limit(500)` on both `workspaces` and `funnel_items` with no cursor. Once either table exceeds 500 rows, items silently disappear.
- **PERF-P0-4:** `src/hooks/useAdminData.ts:220-227` — sequential `user_roles` upsert → `profiles` update → `workspaces` update. If independent, `Promise.all` cuts latency ~3×.
- **PERF-P1-5:** 166 `select('*')` occurrences across hooks — pervasive over-fetch that defeats index-only scans. Narrow columns per usage.
- **PERF-P1-6/7:** `useWorkspaceData.ts:12-44,150-168` — N+1 across workspace cards on dashboards (actions + profiles fetched per workspace). Batch at parent level or add a joining view.
- **PERF-P1-8:** `EcosystemTable.tsx:118-222` — bulk restore/delete/stage-change issue one query per record. Wrap in a single `rpc()` transaction.
- **PERF-P1-9/10:** Most list hooks (KPIs, sessions, activity logs, notifications) have no `.range()` / pagination cap. Only 53 of hundreds of query sites bound results. Default page size 25-50.
- **PERF-P2-11/12:** `EcosystemTable.tsx` renders desktop+mobile row lists twice with no `React.memo`; `AdminUsersManager.tsx` re-filters full user list on every keystroke — memoize.
- **PERF-P2-14:** Verify realtime channel cleanup in `useRealtimeWorkspaces.ts:11`, `useNotifications.ts:79`, `useMessaging.ts:151`, `ChatTab.tsx:180`, `CollaborativeNotesEditor.tsx:92` — grep-verified subscription creation but not each `useEffect` cleanup.
- **PERF-P2-16:** Confirm cron functions (`run-ecosystem-snapshot`, `recompute-health-scores`, `recompute-workspace-alerts`) don't per-row `await` — verify batched SQL as workspace count grows.
- **PERF-P2-18:** Suggested composite indexes on hot filter columns: `workspaces(status, program_id, stage)`, `funnel_items(stage, program_id, owner_consultant_id)`, `action_items(workspace_id, status)`. Requires migration.
