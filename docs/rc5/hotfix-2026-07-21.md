# RC5 Hotfix — 2026-07-21 (Batch A closed)

## Batch A — Past-meeting recorder (`public.log_completed_session_atomic`)

**Status: ✅ GO**

### Defects found while writing the executable 8-scenario harness

Both were regressions that would have surfaced the first time a real
consultant, founder, or mentor tried to log a past meeting — the RPC would
have failed with `undefined_column` before RLS could authorize them.

| # | Defect | Fix |
|---|---|---|
| 1 | `workspace_users.status = 'active'` — that column does not exist; membership is expressed with `active boolean NOT NULL`. | Replaced with `active = true`. |
| 2 | `mentor_connections.status = 'active'` — the check constraint only allows `pending|accepted|declined`. | Replaced with `status = 'accepted'`. |

Both fixes are in migration
`supabase/migrations/…7_rc5_log_completed_session_atomic_authz_fixes.sql`.
Committed to source and applied to the live database.
