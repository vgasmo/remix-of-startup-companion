## v1.0.0 - Production Release (January 2026)

### 🎯 Core Features by Role

#### Founders
- **One Thing Today**: Dynamic task prioritization based on playbook stage, overdue actions, and check-in status
- **Progress Tracking**: Visual journey progress with stage completion and milestone tracking
- **Visual Canvas Templates**: 13+ graphical templates (BMC, Lean, SWOT, GTM, ICP, etc.) with sticky-note UX
- **Template Review Workflow**: Submit templates for consultant review with AI Coach feedback
- **Monthly Check-ins**: Configurable cadence for progress updates and KPI tracking
- **Investor Readiness**: Dataroom checklist and investor update generation

#### Consultants
- **Consultant Cockpit**: Portfolio view with assigned startups and ecosystem toggle
- **Today View**: Upcoming sessions, overdue founders, health alerts, pending reviews
- **Session Prep**: Role-specific preparation cards with risks, KPI trends, and session history
- **AI Coach**: One-click AI analysis of templates with action recommendations
- **Lead Engine**: Public booking links, funnel management, and lead-to-startup conversion
- **Intake Routing**: Admin-configurable consultant assignment (single/round-robin modes)

#### Mentors
- **Mentor Directory**: Skills, availability, languages, and sector matching
- **NDA Workflow**: Digital acceptance with audit logging
- **Session Templates**: Structured mentoring sessions with lightweight admin
- **Availability Settings**: Weekly time-slot configuration

#### Investors (Read-only)
- **Signal Dashboard**: Stage progress, milestones, KPI trends
- **Investor Updates**: Monthly update packages generated by founders
- **Dataroom Access**: Tokenized secure links with access tracking

#### Admin
- **Single Pane of Glass**: Unified admin panel with all management functions
- **Program Setup Wizard**: Multi-step program configuration with cloning
- **Feature Flags**: Per-program feature toggles
- **Intake Routing**: Configure which consultant calendars receive first-contact bookings
